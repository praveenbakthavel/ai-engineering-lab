# AI Engineering Lab Command Center

## Repository Purpose

Consolidated future workspace for AI engineering topics, including RAG, AI agents, document extraction, evaluation, prompts, and assistant workflows.

## Scope

This repository is for future AI engineering implementation after the SQL, Python, analytics, data engineering, cloud, and machine learning phases have created enough foundation.

## Objectives

- Keep RAG and AI agent work in one cohesive repository.
- Avoid duplicate active repositories for related AI engineering work.
- Build AI workflows only when the roadmap reaches the AI Engineering phase.
- Maintain clear documentation and tests as implementation is added.

## Technology Stack

Planned technologies may include Python, LangChain, LangGraph, vector databases, document parsing tools, evaluation utilities, FastAPI, Streamlit, and pytest.

## Folder Structure

- `rag/`: Retrieval-augmented generation experiments and implementations.
- `agents/`: AI agent workflows and tool-use patterns.
- `document_extraction/`: Document parsing and extraction workflows.
- `evaluation/`: Evaluation methods, test datasets, and scoring approaches.
- `prompts/`: Prompt templates and prompt engineering notes.
- `docs/`: Repository documentation.
- `tests/`: Automated tests.

## Development Guidelines

- Keep this repository inactive until the roadmap reaches the AI Engineering phase.
- Do not duplicate work in `rag-projects` or `ai-agents`.
- Keep examples public-safe and avoid private strategy, resume archives, credentials, or confidential data.
